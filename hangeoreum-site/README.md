# 한걸음

정적 웹 호스팅용 프로토타입입니다. 빌드 도구나 외부 라이브러리 없이 `index.html`만으로 실행됩니다.

## 배포

이 저장소의 GitHub Pages에서 `main` 브랜치의 저장소 루트를 게시합니다. 한걸음은 기존 저장소 페이지를 유지하기 위해 `hangeoreum-site/` 경로에 게시되며, 공개 주소는 `https://leeheonjae07.github.io/k-culture-note-demo/hangeoreum-site/`입니다.

## 범위

현재 “실전 예약”은 화면 흐름을 보여주는 시연 기능입니다. 실제 식당·교통 예약, 운행 정보 조회, 결제는 연결되어 있지 않습니다. 실제 거래 기능을 제공하려면 검증된 서버/API 연동과 운영·보안 검토가 별도로 필요합니다.
