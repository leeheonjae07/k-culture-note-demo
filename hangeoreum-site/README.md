# SMART RESERVE

기차·고속/시외버스 좌석 선택과 택시 호출 흐름을 체험하는 모바일 우선 교통 통합 프로토타입입니다. HTML, CSS, JavaScript만 사용하며 별도의 빌드 과정이나 유료 API가 필요하지 않습니다.

## 실행

- 로컬에서 `index.html`을 브라우저로 열면 바로 실행됩니다.
- 스마트폰 브라우저에서도 사용할 수 있으며, 입력 중에는 화면 아래 메뉴를 숨겨 키보드와 겹치지 않게 합니다.
- 예약, 즐겨찾기 및 프로필은 브라우저의 `localStorage`에 저장됩니다.
- GitHub Pages에서는 `main` 브랜치의 저장소 루트를 게시하며, 앱은 `hangeoreum-site/` 경로에서 제공됩니다.
- 프로젝트 일정 차트는 `gantt.html`에서 확인할 수 있습니다. M1을 프로젝트 시작 월로 잡은 12개월 예시이며, 인쇄 기능으로 PDF 저장도 가능합니다.

## 제공 기능

- 기차 및 버스 노선·날짜·인원 검색과 가상 시간표
- 열차 등급 선택, 직접 누르는 좌석도, 선택 좌석 수에 따른 자동 요금 계산
- 좌석 선택 및 해제, 이미 선택할 수 없는 좌석 표시
- 카드·간편결제·가상 계좌이체 방법 선택과 테스트 인증번호를 이용한 결제 흐름 연습
- 택시 출발지·목적지 입력, 차량 유형과 가상 요금·시간 안내
- 가상 예약·호출 기록, 취소 시뮬레이션, 프로필 및 즐겨찾기 관리

## 시연 범위

표시되는 운행 일정·요금·좌석은 모두 브라우저에서 생성하는 예시 데이터입니다. 결제 흐름은 화면 내 테스트 인증번호 `246810`을 사용하는 연습용 시뮬레이션이며, 실제 카드·계좌 정보를 입력하거나 저장하지 않습니다. 실제 운행 정보, 좌석 재고, 예약, 택시 호출 또는 결제 시스템과 연결되어 있지 않으며 실제 예약·이동 요청·청구가 발생하지 않습니다.
